# Urna Guard

Extensão para Chrome, Edge e Firefox que sinaliza, sem ocultar, posts no X com sinais de desinformação sobre a urna eletrônica brasileira. Funciona 100% localmente.
*Extension for Chrome, Edge and Firefox that flags, without hiding, posts on X with signs of disinformation about Brazil's electronic voting machine. 100% local.*
