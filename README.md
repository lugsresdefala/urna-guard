# Urna Guard

Extensão para Chrome, Edge e Firefox que sinaliza, sem ocultar, posts no X com sinais de desinformação sobre a urna eletrônica brasileira. Funciona 100% localmente.

- Site e instalação: https://lugsresdefala.github.io/urna-guard/
- Código-fonte da extensão: [`ext/`](ext/)
- Pacotes: [`downloads/`](downloads/)

Heurísticas, não provas. Não use para assediar ninguém.
